Desarrollo de sitio web informativo One Page para el consultorio dental del Odontólogo Alexis Torres en Xalapa, Veracruz. El proyecto fue diseñado con una estética limpia y moderna para transmitir confianza, profesionalismo y cercanía a los pacientes.

Construido con Astro y JavaScript para ofrecer máxima velocidad de carga y excelente rendimiento, incluye navegación interactiva con slider de servicios, sección de testimonios, integración con Google Maps, agendamiento directo de citas y un blog administrable para la publicación de artículos de salud bucal y posicionamiento SEO.
